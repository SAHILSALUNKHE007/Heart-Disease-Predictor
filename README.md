# ❤️ Heart Disease Predictor

This project is a **machine learning–based web application** that predicts the risk of heart disease using user-provided medical parameters.  
It is built using **Python**, **Scikit-learn**, and **Streamlit**, and deployed on **Streamlit Community Cloud**.

---

## 🚀 Features
- Interactive Streamlit web interface
- Real-time heart disease risk prediction
- Logistic Regression machine learning model
- Proper feature scaling and encoding
- Displays prediction with probability score
- Cloud deployment using GitHub + Streamlit

---

## 📊 Input Parameters
- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Resting ECG
- Maximum Heart Rate
- Exercise Induced Angina
- Oldpeak (ST Depression)
- ST Slope

---
